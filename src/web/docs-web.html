Web app tutorial

Create charts without Excel by working with data directly in your browser, then export the result as SVG or PNG.

Step 1

Start with data

Open the web app. It opens with sample SPC data. To use your own data, choose Open CSV and select a CSV, TSV, or text file, or paste a tabular block copied from Excel directly into the grid.

Grid structure: row 1 holds the column names. Add at least one named column and one data row before the sheet becomes available to the chart panel.

Step 2

Manage sheets and data

Each imported file becomes a sheet. Select a sheet tab to edit it; use the + tab to add a blank sheet and double-click a sheet tab to rename it. Use + 20 rows and + Column when the grid needs more space.

Edits update the chart preview automatically. The current workbook is stored locally by the browser so it is available the next time you open the app on the same device and browser.

Step 3

Select chart fields and settings

  1. Choose a worksheet. The chart panel follows the active sheet tab.
  2. Choose the table. Each populated sheet is exposed as one table.
  3. Choose category and numerator columns. These fields are required.
  4. Select a chart type. Choose SPC or Funnel and adjust settings in the panel.

The chart appears in the centre panel and updates while you edit the grid or modify chart settings.

Step 4

Export a chart

Select SVG to download a scalable vector image, ideal for reports and editing in graphics software. Select PNG to download a bitmap image for slides, documents, or email. Exported files are created locally in your browser.

Step 5

Install and work offline

Visit the HTTPS-hosted web app once, then use the browser's Install app option in Chrome or Edge, or Add to Dock in macOS Safari. The installed app and these tutorials are cached for offline access.

Privacy: imported data, workbook storage, calculation, and chart rendering all remain in the browser. The web app has no application API or database and does not send worksheet data to a server.

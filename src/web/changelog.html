3 September 2026

Web, Excel, and documentation improvements

Added

  • Separate, step-by-step tutorials for the Excel add-in and web app.
  • A documentation hub and this changelog page, available in the deployed site and offline cache.
  • Progressive web app metadata, valid installation icons, and desktop installation support for the HTTPS-hosted web app.

Changed

  • The Excel worksheet selector now follows the worksheet activated by the user.
  • The embedded chart panel in the web app now follows the active sheet tab, including blank sheets.
  • Workbook saving is deferred until the browser is idle, trailing blank rows are omitted from stored data, and oversized cached workbooks are not retained.

Fixed

  • Corrected progressive web app (PWA) manifest icon references so browsers can recognize the hosted app as installable.
  • Updated service-worker cache versions when offline app-shell content changed.
